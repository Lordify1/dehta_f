## ✔ Step 2: Create a Simple Avatar Picker / File Upload Popup

You already have `showAvatarPicker` in state. Let’s use it properly.

Add this right under your main section:

```jsx
{showAvatarPicker && (
  <div className="fixed inset-0 bg-black bg-opacity-50 flex items-center justify-center z-50">
    <div className="bg-white p-4 rounded-lg shadow-lg w-80">
      <h3 className="text-lg font-semibold mb-3">Update Profile Image</h3>

      {/* Upload Input */}
      <input
        type="file"
        accept="image/*"
        onChange={(e) => {
          const file = e.target.files?.[0];
          if (!file) return;

          const reader = new FileReader();
          reader.onload = function (ev) {
            handleAvatarSelect(ev.target?.result);
          };
          reader.readAsDataURL(file);
        }}
        className="mb-4"
      />

      <div className="flex justify-end gap-2">
        <button
          className={`${classMap.button()} bg-gray-300`}
          onClick={() => setShowAvatarPicker(false)}
        >
          Cancel
        </button>
      </div>
    </div>
  </div>
)}
```

This lets users upload an image, and the preview updates instantly.

## ✔ Step 3: Make Sure the Avatar Actually Updates in Your DB

Inside your existing `EditProfile` form or wherever you're saving user details, ensure you include:

```js
avatar: data.avatar
```

If your `/profile/update` backend route accepts it, you’re golden.
If not, you might need:

```js
formData.append("avatar", data.avatar)
```

(depends on your backend… not trying to fight your API today.)

---

## ✔ Step 4: Replace the Avatar Everywhere

Your `img` tag should use:

```jsx
src={data.avatar}
```

instead of:

```jsx
src={user?.avatar}
```

because what's the point of updating state if the UI ignores it like a toxic ex.
